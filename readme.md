# Anime Fight Arena

Jogo de luta 2D feito com HTML, CSS e JavaScript. Não precisa instalar dependências.

## Como iniciar no Windows

Abra o PowerShell e execute:

```powershell
cd "C:\Users\aluno\OneDrive\clover time2\clover time 2d - Copia"
python -m http.server 8000
```

Depois abra [http://localhost:8000](http://localhost:8000) no navegador. Para encerrar o servidor, volte ao PowerShell e pressione `Ctrl+C`.

Se o comando `python` não estiver disponível, tente `py -m http.server 8000` no lugar.

Este projeto não tem `package.json`; por isso, `npm start` não é o comando usado para iniciar o jogo.

## Controles

- `A` / `D`: mover para a esquerda / direita
- `W`: pular
- `S`: defender
- `J`: ataque básico
- `K`: golpe forte
- `L`: poder especial
- Asta: `U` onda cortante, `I` meteoro negro
- Yuno: `O` tornado de vento, `P` tempestade estelar
- Yami: `U` corte dimensional
- Noelle: `U` dragão do mar
